# ミニストーリーと固有名詞を整える

中国語DUO向けの参照資料。Narrative Designerの人物の一貫性・設定の整合・独立した断片同士のつながりを、短い学習文のレビュー向けに翻案した。[出典・ライセンス](README.md)を参照。

## 採用する考え方

- 関連する例文の人物・場所・出来事を揃え、前後で何が起こったかを短く追えるようにする。ストーリーの都合で学習目標を変えない。
- 各例文の会話上・物語上の役割を確認する。情報を教えるためだけの不自然な説明台詞になっていないかを見る。
- 人物の関係・口調・既知の事実を維持する。前の文と矛盾する時刻、行動、関係、出来事を候補として記録する。
- つながりが記憶の手がかりになるようにしつつ、任意の背景知識や離れた文を知らないと理解できない箇所を確認する。独立性の要件は既存の学習形式に合わせる。

## 固有名詞と連続性のレビュー観点

既存の人物表・設定資料があれば再利用し、競合する設定集を新設しない。後日レビューを行う場合、次の事項を確認する。

| 観点 | 確認する内容 |
| --- | --- |
| 人物・場所の参照 | 同じ対象を指す名前・識別子が追跡できるか |
| 表記 | 漢字表記、別名、必要な場合のピンイン・訳名が承認済み表記と整合するか |
| 同名・別名 | 同じ名前の別人や、同一人物の別名を誤って統合していないか |
| 人物の関係 | 立場・呼称・話し方が場面と前後の文に合うか |
| 出来事 | 時系列、原因と結果、既に確定した事実に矛盾がないか |
| 学習との対応 | ストーリー内の各例文が計画上の語彙・文法用法を保っているか |

疑問点は該当する文の参照と理由を添えて記録し、名前や設定を一括置換しない。固有名詞の再登場はつながりを作るための意図的な反復になり得る。

会話の自然さ、語法、語順、語域、文化的な妥当性は別の中国語レビューで確認する。設定の整合だけで自然な中国語と判定しない。[学習設計](learning-design.md)と[品質レビュー](content-quality.md)も参照する。

ゲーム用の分岐システム、エンジン連携、計測機能、演出実装、上流の人物像・台詞例・数値目標は採用しない。この資料により新規ストーリーや固有名詞の大量生成を許可するものではない。
