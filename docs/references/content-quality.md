# 網羅漏れと意図しない重複をレビューする

中国語DUO向けの参照資料。Data Quality Frameworksの完全性・一意性・妥当性・整合性と、項目単体から関連項目へ確認する考え方を翻案した。[出典・ライセンス](README.md)を参照。

## レビューの前提

承認済みの語彙・文法計画とレビュー対象の版・範囲を特定する。以下は将来のレビュー時の観点であり、今回チェック機能やデータ形式を実装・実行したという意味ではない。計画・例文がない状態で欠落数、重複数、網羅率を報告しない。

| 観点 | 確認内容 | 扱い |
| --- | --- | --- |
| 完全性 | 計画内の語彙・文法用法に例文の対応先があるか | 未対応と、計画や対応根拠が不明な状態を区別する |
| 一意性 | 識別子の衝突、同文・類似文の予定外の再登録がないか | 学習項目・語句・固有名詞の再出現は一律に禁止しない |
| 妥当性 | 必須情報、参照先、用法の区分が既存の形式・計画に合うか | 新しいスキーマや数値閾値を勝手に定めない |
| 整合性 | 項目から例文、例文から項目への対応と人物・場面の参照が矛盾しないか | 切れた参照や説明できない差異を候補として記録する |
| 正確性 | 実際の文が対象語義・文法用法を示しているか | 単純な文字列一致で確定せず、内容を読む |
| 版の整合 | 対象計画と例文が同じ承認済み版を参照しているか | 更新日時だけで学習文を陳腐化扱いしない |

## 意図的な反復を守る

重複候補は「計画された復習」「ストーリー上の再登場」「未計画の重複」「判断保留」のように、理由に基づいて整理する。既存の分類がある場合はそれに従う。

- 同じ語彙を異なる文脈で使うことや、同じ文法を定着のために再訪することは、直ちに不備ではない。
- 完全一致の文も候補として目的を確認する。完全一致だけを根拠に自動削除しない。
- 類似度や表記の正規化は、異なる語義・用法・固有名詞を誤って同一視し得る。候補抽出と削除判断を分ける。
- 反復の意図が見つからない場合も判断保留にできる。網羅数を増やすための追加・置換や、重複数を減らすための教材削除を暗黙に行わない。

## 所見を残す場合

対象の版、項目・例文の参照、期待した状態、観察した状態、反復意図の根拠、判断保留の理由を残す。構造・対応・網羅の所見と、中国語の自然さの所見を分け、未レビューの項目を合格扱いしない。中国語の自然さ、語法、語順、語域、文化的妥当性は別途レビューする。

計画への対応は[学習設計](learning-design.md)、人物・固有名詞の整合は[物語設計](mini-story-design.md)を参照する。上流のGreat Expectations、dbt、CI、インストール手順やコード例は採用しない。ランタイムスキル、検証パイプライン、フックは追加しない。
