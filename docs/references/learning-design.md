# 語彙・文法と例文の対応を計画する

中国語DUO向けの参照資料。Corporate Training Designerの学習目標・段階設計・評価との対応を、この用途に限定して翻案した。[出典・ライセンス](README.md)を参照。

## 採用する考え方

- 承認済みの語彙・文法計画を出発点にし、各項目で学習者が何を理解・使用できるようになるかを明確にする。
- 学習目標と例文・確認方法を対応させる。単に同じ文字列が含まれることと、狙った意味・文法用法が示されていることを分ける。
- 前提知識、初出、後の復習の順序を確認する。反復には導入・定着・文脈を変えた復習などの意図を持たせる。
- 網羅のためだけに不自然な例文へ項目を詰め込まない。対応数と学習の質を同一視しない。

## 対応表のレビュー観点

後日、計画や教材のレビューを依頼された場合の観点であり、ここで新しいデータ形式やカリキュラムを決定するものではない。既存の識別子・形式がある場合はそれを使う。

| 観点 | 確認する内容 |
| --- | --- |
| 計画の根拠 | 対象とする語彙・文法一覧、版、レビュー範囲が特定できるか |
| 学習項目 | 表記だけでなく、対象の語義・用法・前提項目が分かるか |
| 対応先 | どの例文が主対象として扱い、どれが補助・復習なのか追跡できるか |
| 学習順序 | 未導入項目への依存や、負荷の急な増加がないか |
| 反復意図 | 同じ項目の再出現が計画された復習か、未整理の重複か |
| 評価状態 | 構造・網羅の確認と、中国語の自然さのレビュー状態を別に示せるか |

計画にある項目から例文への方向と、例文から計画項目への方向の両方を見る。計画が未提示なら網羅率や欠落を断定せず、根拠不足として記録する。新しい項目を暗黙に追加して欠落を埋めない。

例文間のつながりは[物語設計](mini-story-design.md)、欠落・重複候補の扱いは[品質レビュー](content-quality.md)を参照する。企業研修のROI、プラットフォーム、配信、予算、数値目標は採用しない。教材作成や学習効果の検証をこの文書だけで開始しない。
